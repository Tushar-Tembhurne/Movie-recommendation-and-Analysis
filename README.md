🎬 Movie Recommendation & Analytics Dashboard

A light-weight, interactive Streamlit web application that delivers real-time movie insights, genre distributions, and personalized recommendations—built entirely using pure Python and Object-Oriented Programming principles.


### 📌 Project Overview

* **Pure Python Architecture:** Developed completely in pure Python using Object-Oriented Programming (OOP) principles, avoiding heavy dependencies like Pandas for clean, light-weight execution.
* **Interactive Streamlit Interface:** Features a responsive user interface with multi-tab navigation for exploring metrics, filtering movies, and viewing recommendations.
* **Real-Time Data Processing:** Implements dynamic sorting and custom filtering logic to handle search queries, genre filters, and rating evaluations instantly.
* **Algorithmic Movie Recommendations:** Suggests tailored film recommendations based on user-selected preferences, ratings, and genre parameters.
* **Automated Data Validation:** Validates input datasets to filter out corrupted or missing entries before processing analytics.
* **Custom CSV Data Export:** Built-in manual CSV generator that allows users to export filtered movie records directly to their local system.
